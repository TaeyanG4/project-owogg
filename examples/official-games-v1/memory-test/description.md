# Sequence Memory Test

Sequence Memory Test is a free browser game in which you watch a pattern on four colored pads and repeat it in the same order. Each completed level adds to the challenge, so your score reflects the highest verified level you clear.

## How to play

1. Start the test and watch the colored pads light up.
2. Remember the complete sequence without pressing during playback.
3. Select the pads in exactly the same order.
4. Complete the sequence to advance to the next level.

You can use a mouse, touch screen, or keyboard. Keeping distractions low and waiting for the full pattern before answering usually produces a more consistent attempt.

## How scoring works

The score is the number of levels completed, with higher scores ranking above lower scores. A server-approved challenge determines the sequence, and OWOGG independently regenerates the expected pattern to verify the submitted round evidence. The current standard challenge contains eight levels.

## Frequently asked questions

### What kind of memory does this game use?

It mainly exercises short-term sequence recall and sustained attention. It is a casual brain game and does not diagnose memory or health conditions.

### Does the pattern change between attempts?

Yes. A new challenge can produce a different sequence while still allowing the server to verify the result.

### Can I pause while the pattern is playing?

No. An attempt is designed to continue level by level. Restart if the session is interrupted.
