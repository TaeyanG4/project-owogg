# 위키/사이트 번역 콘텐츠 저장소 (i18n-content)

**경로**: `docs/i18n-content/` (저장소 루트 기준)

이 폴더는 OwOGG 위키·정책 문서·게임 카탈로그에서 다국어(ko-KR/en-US/ja-JP/zh-CN) 처리가
필요한 콘텐츠 전체를 모아둔 곳입니다. 문서는 성격에 따라 둘로 나뉩니다 — **바뀌지 않는 규칙**과
**계속 갱신되는 진행 상황**을 한 파일에 섞어두면 나중에 뭐가 최신인지 헷갈리기 때문입니다.

| 문서                       | 성격                       | 내용                                                                             |
| -------------------------- | -------------------------- | -------------------------------------------------------------------------------- |
| [`GUIDE.md`](./GUIDE.md)   | 📌 지침 (거의 변하지 않음) | 한국어=원본 원칙, 번역 지침 7항목, 최신화 확인 도구 사용법, 시나리오별 대응 방법 |
| [`STATUS.md`](./STATUS.md) | 🔄 진행 상황 (계속 갱신됨) | 파일별 번역 완료/대기 상태, 최신화(드리프트) 상태, 다음 할 일 우선순위           |

**처음 이 폴더를 보신다면**: 규칙이 궁금하면 `GUIDE.md`, 지금 뭐가 끝났고 뭐가 남았는지 궁금하면
`STATUS.md`를 먼저 보세요.

## 콘텐츠 파일 요약

- `translated-streamer.json`, `translated-account-games.json`, `01-wiki-discord.json` — ✅ 이미
  번역되어 코드에 연결된 위키 본문 16페이지 전체 (구조/상세는 `STATUS.md` 참고)
- `02-game-content.json`, `03-terms-privacy.json` — ⏳ 한국어 원문만 있는 번역 대기 파일
  (번역 방법은 `GUIDE.md`, 대상 목록은 `STATUS.md`)
- `ko-source-snapshot.json` — 자동 최신화 확인 도구(`pnpm i18n:sync-check`)가 쓰는 상태 파일.
  직접 수정하지 마세요 (`GUIDE.md` 참고).
