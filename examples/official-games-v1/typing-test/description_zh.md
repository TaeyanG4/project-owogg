# 打字速度测试

打字速度测试是一款免费的 90 秒浏览器小游戏，用于测量输入速度和准确率。选择韩文、英文、日文或中文文章，逐行输入后即可查看经过验证的 WPM、CPM、准确率和综合分数。

## 游戏方法

1. 选择文章语言并开始测试。
2. 按照屏幕内容准确输入当前高亮的一行。
3. 继续逐行输入，直到 90 秒计时结束。
4. 查看综合分数、每分钟单词数、每分钟字符数和准确率。

若要比较成绩，建议每次使用相同的键盘布局和文章语言。纠正错误可以提高准确率；快速输入大量错误字符可能会降低综合分数。

## 成绩计算方式

WPM 根据正确字符数计算，CPM 根据全部输入字符数计算，准确率则是正确字符占全部输入字符的比例。综合分数会结合 WPM 与 CPM，并乘以准确率因素。OWOGG 会把提交的输入证据与服务器批准的文章顺序和经过时间进行核对，再接受结果。

## 常见问题

### WPM 和 CPM 是什么？

WPM 是根据正确字符估算的每分钟单词数，CPM 是每分钟输入字符数。由于文字系统和输入方式不同，游戏会同时显示两项指标。

### 可以测试多种语言吗？

可以。游戏提供韩文、英文、日文和简体中文文章。请把每种语言和键盘布局视为不同的比较条件。

### 需要安装软件吗？

不需要。游戏直接在浏览器中运行，只需键盘输入。
