# 반응속도 테스트

반응속도 테스트는 화면이 초록색으로 바뀐 뒤 얼마나 빠르게 반응하는지 측정하는 무료 브라우저 게임입니다. 5개 라운드를 완료하면 밀리초 단위의 검증된 평균 반응 시간이 기록되며, 평균이 짧을수록 높은 순위가 됩니다.

## 플레이 방법

1. 테스트를 시작하고 반응 영역이 준비 상태인 동안 기다립니다.
2. 미리 누르지 마세요. 약 2~8초 사이의 예측하기 어려운 대기 뒤 초록색 신호가 나타납니다.
3. 화면이 초록색으로 바뀌는 즉시 클릭, 터치 또는 지원되는 키보드 입력을 합니다.
4. 총 5개 라운드를 반복합니다.

초록색 신호 전에 누르면 부정 출발로 시도가 종료됩니다. 대기 시간을 예측하기보다 화면 상태를 확인하는 것이 중요합니다.

## 점수 계산 방식

각 라운드는 초록색 신호와 유효한 입력 사이의 시간을 기록합니다. 최종 점수는 5개 기록의 반올림 평균입니다. OWOGG가 서버 승인 신호 일정을 재생성하고 제출된 시간 증거를 확인한 뒤 결과를 반영합니다.

## 자주 묻는 질문

### 좋은 반응속도는 몇 ms인가요?

기기, 화면 지연, 입력 방식, 집중 상태와 환경에 따라 결과가 달라집니다. 의료 기준으로 해석하지 말고 비슷한 조건에서 자신의 기록 변화를 비교해 주세요.

### 휴대전화나 키보드로 할 수 있나요?

네. 마우스, 터치, 키보드 입력을 지원합니다. 같은 입력 방식끼리 비교하면 더 의미 있는 변화를 볼 수 있습니다.

### 라운드마다 대기 시간이 다른 이유는 무엇인가요?

변하는 대기 시간은 신호를 예측하기 어렵게 하여 실제 시각 신호에 반응하도록 합니다.
