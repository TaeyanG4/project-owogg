# タイピング速度テスト

タイピング速度テストは、90秒間の速度と正確さを測る無料ブラウザーゲームです。韓国語、英語、日本語、中国語の文章から1つを選び、1行ずつ入力すると、検証済みのWPM、CPM、正確率、総合スコアを確認できます。

## 遊び方

1. 文章の言語を選んでテストを開始します。
2. 強調された1行を表示どおりに入力します。
3. 90秒のタイマーが終了するまで、次の行を入力し続けます。
4. 総合スコア、1分あたりの単語数、文字数、正確率を確認します。

記録を比べる場合は、同じキーボード配列と言語を使ってください。ミスを修正すると正確率が上がり、誤った文字を急いで多く入力すると総合スコアが下がることがあります。

## スコアの仕組み

WPMは正しい文字数、CPMは入力した全文字数から計算します。正確率は入力文字に対する正しい文字の割合です。総合スコアはWPMとCPMを組み合わせ、正確率を反映します。OWOGGは、サーバー承認済みの文章順と経過時間を入力証拠と照合して結果を受理します。

## よくある質問

### WPMとCPMとは何ですか？

WPMは正しい文字入力から換算した1分あたりの単語数、CPMは1分あたりの入力文字数です。文字体系や入力方法の違いを考慮できるよう、両方を表示します。

### 複数の言語を試せますか？

はい。韓国語、英語、日本語、簡体字中国語に対応しています。言語とキーボード配列ごとに別の条件として比較してください。

### インストールは必要ですか？

いいえ。ブラウザー上で動作し、キーボード入力だけで利用できます。
