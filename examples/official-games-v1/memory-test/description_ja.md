# 順番記憶テスト

順番記憶テストは、4色のパッドが光るパターンを見て、同じ順番で入力する無料ブラウザーゲームです。レベルが上がるほど課題が長くなり、クリアした最高の検証済みレベルがスコアになります。

## 遊び方

1. テストを開始し、色のパッドが光る順番を見ます。
2. 再生中は押さず、最後まで順番を覚えます。
3. まったく同じ順番でパッドを選びます。
4. 正解すると次のレベルへ進みます。

マウス、タッチ画面、キーボードに対応しています。周囲の気を散らすものを減らし、パターンが終わってから入力すると、より安定した記録を測れます。

## スコアの仕組み

クリアしたレベル数がスコアとなり、高いほど上位です。サーバー承認済みのチャレンジが順番を決め、OWOGGが正解パターンを再生成して提出されたラウンド証拠を検証します。現在の標準チャレンジは8レベルで構成されています。

## よくある質問

### どのような記憶を使いますか？

主に短期的な順序記憶と持続的な注意を使います。カジュアルな脳トレゲームであり、記憶力や健康状態を診断するものではありません。

### パターンは試行ごとに変わりますか？

はい。新しいチャレンジは異なる順番を作り、サーバーは同じ規則で検証できます。

### 再生中に一時停止できますか？

いいえ。1回の試行はレベルごとに続きます。中断された場合は再スタートしてください。
