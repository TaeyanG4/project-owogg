# 五目並べ

OWOGG五目並べは、15×15の盤で遊ぶ2人用の戦略ボードゲームです。1台の端末で交互に打つローカル対戦と、OWOGG Relayサービスが利用可能な場合のオンライン対戦に対応します。相手より先に縦・横・斜めの勝利条件を作ることが目的です。

## 遊び方

1. 黒が先手で、黒と白が1手ずつ交互に打ちます。
2. 空いている交点を選び、石を1つ置きます。
3. 自分の列を伸ばしながら、相手の狙いを防ぎます。
4. 対局終了後は新しいローカル対局、またはオンライン再戦を選べます。

## 採用ルール

自由打ち出しで、黒には連珠式の禁手を適用します。黒はちょうど5個を連ねると勝利しますが、長連、三三、四四は禁止です。白は5個以上を連ねると勝利します。黒の禁手は盤面を変更する前に拒否されます。

## ローカルとオンライン

ローカル対戦は2人が同じ画面を共有します。オンライン対戦はOWOGG Relayプロトコルを使用し、ルームホストが基準となるゲーム状態を管理します。切断時の再接続にも対応します。メンテナンス中はオンラインを利用できない場合がありますが、ローカル対戦は別に動作します。

## よくある質問

### ランキングはありますか？

いいえ。現在のバージョンはルーム内で勝敗を処理しますが、スコアランキングは公開しません。

### 何人必要ですか？

ローカル、オンラインともに2人ちょうどで遊びます。
