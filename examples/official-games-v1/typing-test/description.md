# Typing Speed Test

Typing Speed Test is a free 90-second browser game that measures typing speed and accuracy. Choose a Korean, English, Japanese, or Chinese passage, type one line at a time, and receive verified WPM, CPM, accuracy, and an overall score.

## How to play

1. Choose the passage language and start the test.
2. Type the highlighted line exactly as shown.
3. Continue line by line until the 90-second timer ends.
4. Review your overall score, words per minute, characters per minute, and accuracy.

For comparable results, use the same keyboard layout and passage language between attempts. Correcting mistakes can improve accuracy, while rushing with many incorrect characters can reduce the overall score.

## How scoring works

WPM is calculated from correct characters, CPM from all typed characters, and accuracy from the ratio of correct to typed characters. The overall score combines WPM and CPM, then applies the accuracy rate. OWOGG compares the submitted input evidence with the server-approved passage order and elapsed time before accepting the result.

## Frequently asked questions

### What do WPM and CPM mean?

WPM estimates words per minute from correct character input. CPM counts typed characters per minute. Both are shown because writing systems and input methods differ.

### Can I test several languages?

Yes. Korean, English, Japanese, and Simplified Chinese passages are available. Treat each language and keyboard layout as a separate comparison condition.

### Does this test install anything?

No. It runs in the browser and only needs keyboard input.
