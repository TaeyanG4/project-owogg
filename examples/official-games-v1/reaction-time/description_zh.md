# 反应速度测试

反应速度测试是一款免费的浏览器小游戏，用于测量屏幕变绿后你的反应速度。完成 5 轮后，系统会以毫秒记录经过验证的平均反应时间；平均值越短，排名越高。

## 游戏方法

1. 开始测试，在反应区域处于等待状态时保持等待。
2. 不要提前按下。约 2～8 秒的随机等待后会出现绿色信号。
3. 屏幕变绿后立即点击、触碰或按下支持的键盘按键。
4. 重复完成全部 5 轮。

在绿色信号出现前操作会被判为抢跑，并结束本次尝试。请观察屏幕变化，不要猜测等待时间。

## 成绩计算方式

每轮记录绿色提示与有效输入之间的时间。最终成绩是 5 次记录四舍五入后的平均值。OWOGG 会重建服务器批准的提示时间表，并验证提交的计时证据后再接受结果。

## 常见问题

### 多少毫秒算是好的反应速度？

结果会受到设备、显示延迟、输入方式、注意状态和环境影响。请把它用于比较相似条件下自己的成绩，不要将其视为医疗标准。

### 可以使用手机或键盘吗？

可以。游戏支持鼠标、触摸和键盘。使用相同输入方式进行比较，更容易观察有意义的变化。

### 为什么每轮等待时间不同？

变化的等待时间可以减少预判，让测试更专注于对可见信号的真实反应。
