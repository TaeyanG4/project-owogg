# 에임 테스트

에임 테스트는 표적을 얼마나 빠르고 정확하게 클릭하거나 터치하는지 측정하는 무료 브라우저 게임입니다. 보통 모드에서는 20개, 어려움 모드에서는 더 작은 표적 30개를 순서대로 맞혀 가장 짧은 완료 시간을 기록해 보세요.

## 플레이 방법

1. 난이도를 선택하고 테스트를 시작합니다.
2. 원형 표적이 나타나는 즉시 클릭하거나 터치합니다.
3. 난이도에서 요구하는 유효한 표적을 모두 맞히면 검증된 결과가 기록됩니다.

보통 모드는 표적이 더 크고, 어려움 모드는 정교한 포인터 조작이 더 필요합니다. 마우스, 트랙패드, 터치 화면을 사용할 수 있습니다. 자신의 기록을 공정하게 비교하려면 같은 기기와 입력 방식을 유지하는 것이 좋습니다.

## 점수 계산 방식

시작부터 마지막 유효 타격까지 걸린 전체 시간을 밀리초로 계산하며, 시간이 짧을수록 높은 순위가 됩니다. OWOGG 서버가 승인한 challenge로 표적 순서를 만들고, 순차 타격 증거를 검증한 뒤 결과를 반영합니다.

## 자주 묻는 질문

### 에임 테스트로 무엇을 연습할 수 있나요?

시각적 주의력, 포인터 조작, 빠른 표적 선택을 연습할 수 있습니다. 가벼운 실력 테스트이며 의료·전문 진단 도구는 아닙니다.

### 표적 위치는 매번 같나요?

아닙니다. 시도마다 재현 가능하지만 달라지는 challenge가 표적 순서를 결정합니다.

### 모바일에서도 할 수 있나요?

네. 터치 입력을 지원합니다. 다만 터치와 마우스 기록은 입력 조건이 다르므로 따로 비교하는 편이 좋습니다.
