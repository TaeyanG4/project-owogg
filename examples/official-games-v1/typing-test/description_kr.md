# 타자 속도 테스트

타자 속도 테스트는 90초 동안 타자 속도와 정확도를 측정하는 무료 브라우저 게임입니다. 한국어, 영어, 일본어, 중국어 지문 중 하나를 골라 한 줄씩 입력하면 검증된 WPM, CPM, 정확도와 종합 점수를 확인할 수 있습니다.

## 플레이 방법

1. 지문 언어를 선택하고 테스트를 시작합니다.
2. 강조된 한 줄을 화면에 나온 그대로 입력합니다.
3. 90초 타이머가 끝날 때까지 다음 줄을 계속 입력합니다.
4. 종합 점수, 분당 단어 수, 분당 타수와 정확도를 확인합니다.

기록을 비교할 때는 같은 키보드 배열과 지문 언어를 사용하는 것이 좋습니다. 오타를 수정하면 정확도를 높일 수 있으며, 틀린 글자를 많이 입력하면 종합 점수가 낮아질 수 있습니다.

## 점수 계산 방식

WPM은 올바르게 입력한 글자를 기준으로, CPM은 입력한 전체 글자를 기준으로 계산합니다. 정확도는 전체 입력 중 올바른 글자의 비율입니다. 종합 점수는 WPM과 CPM을 함께 반영한 뒤 정확도를 적용합니다. OWOGG는 서버가 승인한 지문 순서와 경과 시간을 제출된 입력 증거와 대조한 뒤 결과를 반영합니다.

## 자주 묻는 질문

### WPM과 CPM은 무엇인가요?

WPM은 올바른 글자 수에서 환산한 분당 단어 수이고, CPM은 분당 입력 글자 수입니다. 문자 체계와 입력 방식의 차이를 고려할 수 있도록 두 값을 함께 보여 줍니다.

### 여러 언어를 테스트할 수 있나요?

네. 한국어, 영어, 일본어, 간체 중국어 지문을 지원합니다. 언어와 키보드 배열마다 별도의 조건으로 기록을 비교해 주세요.

### 별도 프로그램을 설치해야 하나요?

아니요. 브라우저에서 실행되며 키보드 입력만 필요합니다.
