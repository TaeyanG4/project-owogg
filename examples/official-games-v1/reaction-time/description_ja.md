# 反応速度テスト

反応速度テストは、画面が緑色に変わってからどれだけ速く反応できるか測る無料ブラウザーゲームです。5ラウンドを完了すると、検証済みの平均反応時間がミリ秒で記録され、短いほど上位になります。

## 遊び方

1. テストを開始し、反応エリアが待機状態の間は待ちます。
2. 早押ししないでください。約2～8秒の予測しにくい待ち時間の後、緑色の合図が出ます。
3. 画面が緑色になったら、すぐにクリック、タップ、または対応するキー入力をします。
4. 全5ラウンドを繰り返します。

緑色になる前に押すとフライングとなり、その試行は終了します。待ち時間を予測せず、画面の変化を確認することが大切です。

## スコアの仕組み

各ラウンドで、緑色の合図から有効な入力までの時間を記録します。最終スコアは5回の記録を丸めた平均値です。OWOGGはサーバー承認済みの合図スケジュールを再生成し、提出された時間証拠を検証します。

## よくある質問

### 良い反応時間は何ミリ秒ですか？

端末、画面遅延、入力方法、集中状態、環境によって変わります。医療的な基準ではなく、似た条件で自分の記録を比べるために利用してください。

### スマートフォンやキーボードでも遊べますか？

はい。マウス、タッチ、キーボードに対応しています。同じ入力方法どうしで比べると傾向を確認しやすくなります。

### 待ち時間が毎回違うのはなぜですか？

予測を難しくし、実際に表示された合図へ反応するテストにするためです。
