# 순서 기억력 테스트

순서 기억력 테스트는 네 가지 색상 패드가 빛나는 패턴을 보고 같은 순서로 입력하는 무료 브라우저 게임입니다. 레벨이 올라갈수록 도전이 길어지며, 통과한 가장 높은 검증 레벨이 기록이 됩니다.

## 플레이 방법

1. 테스트를 시작하고 색상 패드가 빛나는 순서를 봅니다.
2. 재생 중에는 누르지 말고 전체 순서를 기억합니다.
3. 패드를 정확히 같은 순서로 선택합니다.
4. 순서를 맞히면 다음 레벨로 진행합니다.

마우스, 터치 화면, 키보드를 사용할 수 있습니다. 방해 요소를 줄이고 패턴이 끝난 뒤 입력하면 더 일관된 기록을 측정할 수 있습니다.

## 점수 계산 방식

완료한 레벨 수가 점수이며, 높을수록 상위에 기록됩니다. 서버가 승인한 challenge가 순서를 결정하고, OWOGG가 예상 패턴을 독립적으로 재생성해 제출된 라운드 증거를 검증합니다. 현재 표준 challenge는 8개 레벨로 구성됩니다.

## 자주 묻는 질문

### 어떤 기억력을 사용하는 게임인가요?

주로 짧은 순서 기억과 지속적인 주의 집중을 사용합니다. 가볍게 즐기는 두뇌 게임이며 기억력이나 건강 상태를 진단하지 않습니다.

### 시도할 때마다 패턴이 바뀌나요?

네. 새 challenge는 다른 순서를 만들 수 있으며 서버는 그 결과를 동일한 규칙으로 검증합니다.

### 패턴 재생 중에 일시정지할 수 있나요?

아니요. 한 번의 시도는 레벨별로 계속 진행됩니다. 중간에 방해를 받았다면 다시 시작해 주세요.
