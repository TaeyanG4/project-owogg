# 顺序记忆测试

顺序记忆测试是一款免费的浏览器小游戏。你需要观察四个彩色按键亮起的规律，再按相同顺序输入。完成的关卡越多，挑战越长，最高的已验证通关等级就是你的成绩。

## 游戏方法

1. 开始测试并观察彩色按键亮起的顺序。
2. 播放期间不要点击，先记住完整序列。
3. 按完全相同的顺序选择按键。
4. 正确完成后进入下一关。

游戏支持鼠标、触摸屏和键盘。减少干扰并等图案播放完再输入，有助于得到更稳定的个人成绩。

## 成绩计算方式

成绩为完成的关卡数，关卡越高，排名越高。服务器批准的挑战负责生成序列，OWOGG 会独立重建正确图案并验证提交的每轮证据。目前的标准挑战由 8 个关卡组成。

## 常见问题

### 这款游戏主要使用哪种记忆？

它主要练习短期顺序记忆和持续注意。这是一款休闲益智游戏，不能用于诊断记忆或健康状况。

### 每次尝试的图案都会变化吗？

会。新的挑战可以生成不同序列，同时服务器仍能按照相同规则验证结果。

### 图案播放时可以暂停吗？

不可以。一次尝试会逐关连续进行；如果受到打断，请重新开始。
