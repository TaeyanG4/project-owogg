# 瞄准测试

瞄准测试是一款免费的浏览器小游戏，用于测量你点击或触碰目标的速度与准确性。普通模式需要命中 20 个目标，困难模式则需要命中 30 个更小的目标，并争取更短的完成时间。

## 游戏方法

1. 选择难度并开始测试。
2. 圆形目标出现后立即点击或触碰。
3. 完成当前难度要求的全部有效命中后，系统会记录经过验证的结果。

普通模式的目标较大，困难模式更考验精细的指针控制。游戏支持鼠标、触控板和触摸屏。若要公平比较个人成绩，建议每次使用相同的设备和输入方式。

## 成绩计算方式

成绩是从开始到最后一次有效命中的总用时，以毫秒计算；用时越短，排名越高。OWOGG 会根据服务器批准的挑战生成目标序列，并在接受结果前验证按顺序提交的命中证据。

## 常见问题

### 瞄准测试可以练习什么？

它可以练习视觉注意、指针控制和快速选择目标。这是一项休闲技能测试，不属于医疗或专业评估。

### 每次目标位置都一样吗？

不一样。每次尝试都会获得一个可复现但会变化的挑战，用来决定目标序列。

### 手机可以玩吗？

可以。游戏支持触摸输入，但触摸与鼠标的条件不同，建议分别比较成绩。
