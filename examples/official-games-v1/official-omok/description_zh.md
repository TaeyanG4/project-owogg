# 五子棋

OWOGG 五子棋是一款在 15×15 棋盘上进行的双人策略游戏。你可以在同一台设备上轮流落子，也可以在 OWOGG Relay 服务可用时进行在线对战。目标是在对手之前完成横向、纵向或斜向的胜利连线。

## 游戏方法

1. 黑方先手，黑白双方轮流落一子。
2. 选择一个空交叉点放置棋子。
3. 延伸自己的连线，同时阻挡对手的威胁。
4. 对局结束后，可以开始新的本地对局或请求在线再战。

## 本游戏采用的规则

本版本采用自由开局，并对黑方应用连珠禁手。黑方必须恰好连成五子才能获胜，长连、三三和四四均为禁手；白方连成五子或更多即可获胜。黑方的禁手会在棋盘状态改变前被拒绝。

## 本地与在线模式

本地多人模式由两名玩家共享同一屏幕。在线模式使用 OWOGG Relay 协议，由房主维护权威游戏状态，并支持中断后的重新连接。维护期间在线对战可能不可用，但本地模式在结构上独立运行。

## 常见问题

### 五子棋有排行榜吗？

没有。当前版本会在房间内处理胜负，但不会发布积分排行榜。

### 需要几名玩家？

本地和在线对局都必须正好有两名玩家。
