# エイムテスト

エイムテストは、ターゲットをどれだけ速く正確にクリックまたはタップできるか測る無料ブラウザーゲームです。ノーマルでは20個、ハードでは小さなターゲット30個を順番に当てて最短タイムを目指します。

## 遊び方

1. 難易度を選んでテストを開始します。
2. 円形のターゲットが表示されたら、すぐにクリックまたはタップします。
3. 難易度で必要な有効ヒットをすべて完了すると、検証済みの結果が記録されます。

ノーマルはターゲットが大きく、ハードはより正確なポインター操作が必要です。マウス、トラックパッド、タッチ画面に対応しています。自己記録を公平に比べる場合は、同じ端末と入力方法を使ってください。

## スコアの仕組み

開始から最後の有効ヒットまでの合計時間をミリ秒で計測し、短いほど上位になります。OWOGGはサーバー承認済みのチャレンジからターゲット列を生成し、順番どおりのヒット証拠を検証して結果を受理します。

## よくある質問

### 何を練習できますか？

視覚的な注意、ポインター操作、素早いターゲット選択を練習できます。カジュアルなスキルテストであり、医療・専門的な診断ではありません。

### ターゲットの位置は毎回同じですか？

いいえ。試行ごとのチャレンジにより、再現可能でありながら異なる配置になります。

### スマートフォンでも遊べますか？

はい。タッチ入力に対応しています。ただし、タッチとマウスの記録は分けて比べることをおすすめします。
